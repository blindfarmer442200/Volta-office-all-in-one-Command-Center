# Bella Harness v0.2.0

Bella Harness v0.2.0 is the first installable, production-hardened release of
the canonical Bella deterministic-first runtime.

## Included

- Deterministic input and output security gates.
- Governed read-only Mind Trace memory.
- Bella Operator identity, modes, risk, plans, and approval boundaries.
- Mock-only, one-use Action Gate authorization.
- Ollama-only 18-scenario model acceptance gate.
- Explicit human correction and privacy-first tuning-data export.
- Private Ollama transport with bounded requests and responses.
- Cloud fallback disabled unless explicitly approved.
- Installed `bella` CLI and production doctor.
- Release checksums and a commit-bound release manifest.

## Verification requirements

This release is published only after:

- Python 3.10 and 3.12 compatibility tests pass;
- the unit-test count remains at or above the established 207-test baseline;
- all 115 deterministic red-team probes pass;
- dependency vulnerability audit passes;
- wheel and source archive build successfully;
- distribution metadata passes `twine check`;
- a clean virtual environment installs the wheel and passes `pip check`;
- installed `bella ask "hello"` succeeds;
- installed `bella doctor --json` reports `ready=true`;
- release checksums and manifest verification pass.

## Important boundary

This release does not enable real email, calendar, payment, file, account,
smart-home, or device-control actions. Action Gate remains a local simulation
with `sideEffectsPerformed=false`.

A deployment is not complete until its selected Ollama model passes all 18 Bella
scenarios on the target host and the operator completes the live doctor,
accessibility, performance, and backup-restoration checks described in
`docs/PRODUCTION_READINESS.md`.

## Install

Download the wheel attached to this release, verify it against `SHA256SUMS`, then
install it into a clean virtual environment:

```bash
python -m venv .venv
. .venv/bin/activate
python -m pip install bella_harness-0.2.0-py3-none-any.whl
bella doctor
bella doctor --live
```

Windows PowerShell activation:

```powershell
.venv\Scripts\Activate.ps1
```

The attached `release-manifest.json` binds the distribution hashes to the exact
release commit and records the passed release gates.
